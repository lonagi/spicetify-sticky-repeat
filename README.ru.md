# Sticky Repeat для Spicetify

Сохраняет выбранный режим повтора при переходе к другой песне: без повтора, очередь или **одна песня**.

[English](README.md)

## Использование

Рядом с обычной кнопкой повтора появляется **замок**. Зелёный цвет означает, что сохранение включено. Выбери повтор одной песни обычной кнопкой Spotify — после переключения следующая песня тоже будет повторяться.

Ручное выключение повтора обычной кнопкой запоминается. Нажатие на замок отключает само расширение. Та же настройка доступна через аватар → **«Сохранять режим повтора»**.

Расширение включено по умолчанию. Состояние переключателя сохраняется после перезапуска. При запуске подхватывается текущий режим Spotify.

## Установка

1. Установи [Spicetify](https://spicetify.app/docs/getting-started).
2. Скачай [sticky-repeat.js](https://raw.githubusercontent.com/lonagi/spicetify-sticky-repeat/main/sticky-repeat.js) в папку `Extensions`. На macOS обычно это `~/.config/spicetify/Extensions/`. Команда `spicetify -c` покажет путь к конфигурации; папка `Extensions` находится рядом с ней.
3. Выполни:

   ```sh
   spicetify config extensions sticky-repeat.js
   spicetify apply
   ```

Если команда `spicetify` не найдена после установки на Mac, используй вместо неё `~/.spicetify/spicetify`. Применение изменений перезапускает Spotify.

## Удаление

```sh
spicetify config extensions sticky-repeat.js-
spicetify apply
```

## Совместимость

Проверено на macOS со **Spotify 1.3.8.620** и **Spicetify 2.46.4**: перенос повтора одной песни, ручное выключение, кнопка с замком и работа после перезапуска. Другие ОС пока не проверялись.

Поддерживаются музыкальные треки и локальные файлы; реклама и подкасты пропускаются. После обновлений Spotify может потребоваться обновить Spicetify и повторно применить изменения. См. [инструкцию Spicetify](https://spicetify.app/docs/faq).

В течение короткого перехода между треками изменения повтора с другого устройства или через нативное меню macOS могут быть неотличимы от автоматического сброса. Обычная кнопка повтора в окне Spotify обрабатывается явно.

Попытки восстановления ограничены окном в 3,6 секунды. Если устаревший запрос завершится после нового выбора пользователя, запускается новое ограниченное окно коррекции.

## Приватность

Расширение не делает собственных сетевых запросов, не собирает аналитику и не запрашивает пароль или токен. Оно использует существующий API плеера Spotify и сохраняет локально только состояние своего переключателя.

## Тесты

Нужен Node.js 22 или новее. Устанавливать зависимости не требуется:

```sh
npm run check
npm test
```

20 автоматических тестов проверяют переключения, ручное выключение, запоздалые ответы, ограничения плеера, запуск расширения и восстановление кнопки после перерисовки. Проверки в самом Spotify выполнены отдельно.

Неофициальное расширение, не связанное с Spotify или Spicetify.
